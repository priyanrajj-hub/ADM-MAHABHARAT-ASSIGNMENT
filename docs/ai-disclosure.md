# AI Disclosure

## Tools Used

This project was built with AI coding assistance:

- **Claude** (Anthropic) — code review, architecture feedback, README drafting
- **Google Antigravity** — code generation, terminal commands, test execution,
  Git operations

## What AI Did

- Generated TypeScript source code for the simulation engine, transition
  logic, metrics module, and unit tests
- Executed `npm install`, `npm test`, and `git push` commands
- Created scenario JSON files based on the specification
- Scaffolded the React frontend

## What AI Did NOT Do

- **Research methodology design**: The decision to model incomplete-information
  environments using layered state spaces, the choice of metrics, and the
  scenario structures are human design decisions reviewed by a human.
- **Statistical analysis**: No statistical claims in this project were generated
  by AI. When empirical results exist (after real participant trials), they
  will be computed from actual collected data.
- **Literature review**: No citations in this project were generated by AI.
  Any future citations will be human-verified.
- **Participant data**: No data in this project is AI-generated participant data.
  All current data is synthetic/demo and labeled as such.

## Verification

All AI-generated code was verified against explicit acceptance criteria:

1. `npm test` — 86 unit tests pass
2. Seed reproducibility — verified via byte-identical JSON comparison
3. Metric clamping — all metrics tested for [0, 1] range including
   pathological inputs
4. Edge cases — zero resources, zero time, invalid actions, fully-revealed
   info states all tested

## Policy

AI should not be cited as a source of research findings from this project.
If this tool is used in a published study, the AI assistance should be
disclosed in the methods section as a development tool, not as a research
contributor.
